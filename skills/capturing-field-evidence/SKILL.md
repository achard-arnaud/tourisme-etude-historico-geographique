# Capturing field evidence

Capture first, interpret later. Preserve wording, location, date/context, medium, and any uncertainty. Create a source note before creating a causal claim. Route the note to a provisional arc, HIL and zoom only when the context is clear. If the user is in field mode and asks for acknowledgement only, do not expand the answer.

## Output
- raw observation;
- source/artefact identifier;
- provisional ARC/HIL/ZOOM;
- questions raised;
- no causal promotion without sourcing.
