# Sourcing historical anchors

Use source roles, not prestige alone. `T0` primary/material; `T1` academic; `T2` institutional synthesis; `T3` navigation/encyclopedia; `T4` field mediation; `T5` exploratory lead.

Major causal claims should normally have independent corroboration across source roles. Wikipedia can navigate and expose gaps but should not close a contested causal claim alone. Record contradictions instead of averaging them away.

For each source note record tier, date, author/institution, scope, claim supported, limitations, and provenance.
