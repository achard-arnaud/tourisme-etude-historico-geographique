# Structuring chronological arcs

An ARC begins and ends when the governing optimum changes materially: political regime, resource system, spatial centre, security environment, trade architecture, legitimacy system, or external configuration.

Each arc records: entry rupture, causal question, drivers, amplifiers, consequences, non-causes, exit rupture, and bridge to the next arc. Avoid ruler-by-ruler periodization unless succession itself changes the system.
