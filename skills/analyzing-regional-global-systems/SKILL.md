# Analyzing regional and global systems

Own **HIL-07_regional-global-system**. Map external actors, routes, alliance options, fiscal-military asymmetries and system shocks, then identify the transmission channel back to the home arc. A Z3/Z4 event is explanatory only when it changes local options, costs, flows or coalition capacity.

Output evidence-backed claim candidates and explicit dezoom handoffs. Do not turn world history into background decoration; every promoted dezoom must return to a local payoff through `composing-side-stories`.
