# Architecture

The root skill is an orchestrator. Sub-skills own judgment-heavy methods; scripts enforce mechanical invariants. Project artefacts are split by chronological arc, analytic HIL, reusable wiki entities, graph relations, source register, bridges, drift audits, questions and final output.

The system is deliberately **arc-first, graph-light**: chronology remains the human reading spine; the graph prevents duplication and supports cross-arc reasoning.
