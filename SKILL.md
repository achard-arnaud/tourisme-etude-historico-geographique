# Tourisme étude historico-géographique

## Core principle
Build the investigation **arc-first**: chronological rupture → causal claims → source anchors → bridges → drift/bias audit → synthesis. Use a Zettelkasten-lite/graph-light layer only after claims stabilize.

## Canonical dimensions
For each chronological arc, assess only relevant layers:
1. institutions/chronology;
2. geography/environment;
3. economy/infrastructure;
4. society/demography;
5. religion/culture/legitimacy;
6. security/coercion;
7. regional/global system;
8. historiography/bias.

Use geographic zooms: `Z0` object/site, `Z1` local/subregional, `Z2` national, `Z3` regional, `Z4` global/systemic.

## Evidence model
Classify sources by role: primary/material → academic → institutional → encyclopedia/navigation → field mediation → exploratory lead. Major causal claims require independent corroboration and explicit confidence: `A` established, `B` solid/qualified, `C` hypothesis, `D` false/indirect lead, `U` unresolved.

## Workflow
1. Capture field note, image, question, quote, or URL without interpretation.
2. Sanitize into source fact / claim / inference / tradition / analogy / question.
3. Route to chronological arc + dimension + geographic zoom.
4. Identify anchor sources and cross-check contradictions.
5. Create a bridge only when two established anchors still lack a necessary mechanism.
6. Audit semantic, temporal, scale, causal, source, survivorship, translation, and teleological drift.
7. Promote stable claims into a graph-light/wiki layer.
8. Write each arc as a causal narrative, distinguishing driver, amplifier, consequence, and non-cause.
9. Integrate useful side material as `Mais aussi`, `Petit détour`, `Point de méthode`, or `Fausse piste` boxes rather than unread annexes.
10. QA coverage, sourcing, contradictions, orphan bridges, duplicates, and chronology before delivery.

## Causal gate
A detail enters the main causal trunk only if it changes resource mobilisation, legitimacy/coalition, cost of governing/defending space, access to flows, or a regime/centre shift. Otherwise keep it as evidence, side-box, analogy, or discarded lead.

## Modes
- **Field:** capture and route; obey short acknowledgement protocols.
- **Research:** source, cross-check, bridge, audit, update.
- **Synthesis:** remove pollution, integrate side-notes, produce README + readable output.
- **Modern:** retain the same layers while substituting modern institutional/economic anchors where needed.
