# Causal map — post-independence

Main political-economic trunk remains:
1948 constitutional continuity and citizenship exclusions
→ 1956 linguistic-nationalist rebalancing
→ 1972/1978 constitutional centralisation and executive transformation
→ 1983–2009 civil war and competing sovereignties
→ 2009–2019 postwar infrastructure, centralisation and debt/external reorientation
→ 2019–2022 fiscal/external crisis and mass protest
→ 2022–2026 stabilisation, debt restructuring and electoral realignment.

Run-2 heritage branch:
colonial built environment / archives / collections
→ postcolonial renaming, selective commemoration and heritage institutions
→ tourism/UNESCO property markets + contested urban redevelopment
→ postwar reconstruction of sites such as Jaffna Fort
→ restitution/provenance diplomacy with the Netherlands
→ heritage becomes a live arena of identity, law, property and bilateral politics.

Gate: this branch enters the main trunk only when it changes land/property incentives, reconciliation politics, state legitimacy, international relations or distributional conflict.
