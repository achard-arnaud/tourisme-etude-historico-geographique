# Sri Lanka language-access regime

The postcolonial language regime is treated as an **access architecture**, not only an identity policy. Sinhala Only redistributed access away from the colonial English-speaking elite but asymmetrically burdened Tamil speakers; later constitutional reforms recognized Tamil and retained English as a link language.
